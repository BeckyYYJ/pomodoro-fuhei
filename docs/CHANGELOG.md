# 版本记录

## v1.0 · 2026-10-29

- 修复从空项目切换到有任务的项目时，edit 按钮短暂成为独立窗口并大量闪烁的问题。
- 番茄钟与正计时、多项目管理及项目统计。
- 待办、进行中、已完成三列看板；拖动修改状态。
- 点击卡片展开步骤，右上角 edit 编辑；右键归档、删除或编辑。
- 卡片进入已完成时记录具体时间，移回其他状态后清除时间。
- 当前项目和全部项目搜索，优先级、标签筛选及多种排序。
- 仅已完成卡片可以归档；当前项目一键归档、项目归档及全局归档入口。
- 归档四列网格，只读查看，删除前确认。
- 浅色与深色主题、字体大小和边距设置。
- 卡片组件与页面职责拆分，测试集中管理，统一构建版本信息。

程序、exe 文件名与 Windows 版本信息统一使用 v1.0。数据库沿用 exe 所在目录中的 pomodoro_data.db，旧表自动兼容升级。
